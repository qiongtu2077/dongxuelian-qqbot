# 已知风险记录

## standalone.js — pkill -9 -f 误杀风险

**位置**：`packages/koishi-plugin-dashboard/standalone.js` 第 352-353 行

```js
execSync("pkill -9 -f 'koishi/lib/worker' 2>/dev/null || true", { timeout: 5000 })
execSync("pkill -9 -f 'node.*koishi start' 2>/dev/null || true", { timeout: 5000 })
```

**触发条件**：koishi.pid 文件不存在时，stopKoishiProcesses 会退回到按命令行字符串匹配的 pkill 方案。

**影响**：若同一台机器运行了多个 koishi 实例或含 "koishi" 关键字的无关进程，会被误杀。

**当前判断**：服务器只跑单实例，暂不处理。如果未来多实例部署，需改为精确 PID 管理或 cgroup 隔离。

**出处**：教训总结.md 已有相关记录。
