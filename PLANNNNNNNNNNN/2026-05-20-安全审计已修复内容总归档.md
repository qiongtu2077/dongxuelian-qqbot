## Phase 4 Dashboard/Server 修复

原报告中 Phase 4 曾列为待修复；本轮已完成。更详细的实现与验证记录见：

`PLANNNNNNNNNNN/2026-05-20-Phase4-Dashboard安全修复归档.md`

| 编号 | 风险点 | 修复内容 |
| --- | --- | --- |
| N4 | 登录密码 `===` 非时序安全 | 登录密码比较改为 `safeCompare(password, stored)` |

| S13 | `httpsGetJson` 无限重定向 | 增加 `MAX_REDIRECTS`，默认 5 次 |
| S14 | `downloadToRuntime` 无重定向限制 | 复用 `MAX_REDIRECTS`，默认 5 次 |
| S15 | NapCat token 通过 URL query 传递 | 改为 HTTP header，不再拼接 `webui_token` query |
| N11 | Dashboard server 无 CSP | 增加 `Content-Security-Policy` 与 `X-Content-Type-Options: nosniff` |
| N12 | GitHub JSON 响应体无大小限制 | 增加 `MAX_JSON_RESPONSE_BYTES`，默认 10MB，超限销毁请求 |
| N13 | 下载超限或失败后临时文件残留 | `downloadToRuntime` 错误路径统一清理 partial 文件 |
| N16 | `query_logs` 直接用用户输入构造正则 | 增加危险正则检测，危险 query 退化为字面量搜索 |
| N18 | deploy task ID 使用 `Math.random` | 改为 `crypto.randomBytes(4).toString('hex')` |
