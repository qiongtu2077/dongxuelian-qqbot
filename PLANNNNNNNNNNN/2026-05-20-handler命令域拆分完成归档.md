## 路由顺序归档

拆分后 `handler.js` 中保留的关键顺序如下：

1. 原有轻量命令仍由 `handler.js` 内部处理。
2. TTS 相关命令调用 `handleVoiceCommand(session, state)`。
3. `今日情绪` 调用 `handleEmotionCommand(session, ctx, state)`。
4. Agent 管理命令调用 `handleAgentCommand(session, ctx, state, { mode: 'management' })`。
5. Plan 命令调用 `handlePlanCommand(session, ctx, state)`。
6. Memory 命令调用 `handleMemoryCommand(session, state)`。
7. 显式 Agent 对话与待确认工具调用 `handleAgentCommand(session, ctx, state, { mode: 'runtime' })`。

`agent-command.js` 使用 `mode` 参数分开管理命令和运行态命令，是为了保持原始顺序：工具管理仍在 Plan/Memory 之前，显式 Agent 和 pending confirm 仍在 Plan/Memory 之后。
