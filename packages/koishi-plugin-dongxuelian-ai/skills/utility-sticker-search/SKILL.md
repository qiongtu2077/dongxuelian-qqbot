# 表情包检索

当群友说“有没有 xxxx 的表情包”“来个 xxxx 图”“发个 xxxx 表情”或表达类似需求时，优先从已有表情包关键词中匹配。

- 已有表情包大致覆盖：绷不住了、你又在狗叫什么、群友怎么这么坏、可以先叫声爸爸、不想活了、考试不及格、假装思考、顺着网线打、请你吃粑粑、多充钱少抱怨、不准发屎、这是大便、连续打你、欧皇真讨厌、急哭了、厉害了、喜欢你、小生气、无语流汗、无语、难过、惊讶、惊醒、偷看、泪目、懵逼、危险等。
- 匹配到时，回复中使用 `[图:关键词]` 触发表情包发送，例如 `[图:无语]`。
- 如果没有完全匹配，选择语义最接近的一张，不要编造不存在的文件名。
- 如果确实没有合适表情包，简短说明没有这张，并顺手给一个接近的替代建议。
